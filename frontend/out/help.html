Help & FAQ

›Does Credon need the backend (the “Credon engine”) running?

Chat works even without it — Credon falls back to answering directly from its model network in your browser. But starting the engine unlocks the full powers: saved chat history, the PDF knowledge library, agent code execution, learning from feedback, and scheduled jobs.

On your own machine: double-click run_backend.cmd (Windows) or run uvicorn app.main:app --app-dir backend --port 8000.

›How do I read PDFs and images?

Click the + button in the chat box, or open Knowledge & PDFs from the sidebar to build a permanent library. PDFs are read in your browser; with the engine running they are also indexed for future questions. Images are understood by Credon Scout.

›What can Agent mode do?

Flip to Agent and give a goal. Credon drafts a plan, searches the web, opens pages, writes files, runs Python in a sandbox, and delivers a report — all streamed live in the Plan / Terminal / Files / Report panel. You can reply with follow-ups like “now change the chart to a bar chart” and it iterates.

›How do I get the browser superpower (Camoufox)?

Optional, one-time, free. In a terminal: pip install "camoufox[geoip]" playwright then camoufox fetch, and set USE_CAMOUFOX=true in your backend .env. Agent research steps can then open JavaScript-heavy or bot-protected pages. Without it, Credon still reads most pages.

›How do exports work?

Long answers get an Open in workspace button — from there export clean PDFs or PowerPoint decks instantly (built on your device). The Export center in the sidebar can export whole chats via the engine.

›Is my data private?

Your profile, prompts and local chats stay on your device. Messages you send are processed by the model providers to generate answers. We never sell data. See the privacy policy.

›Keyboard shortcuts?

⌘K / Ctrl+K new chat · / commands in the composer · Enter send · Shift+Enter newline · Esc close menus.
