# Expense Tracker in Python

## Overview
A lightweight command-line expense tracker with CSV storage, supporting add/update/list operations and a demo run.

## Features
- **Add expenses**: Record date, category, amount, and description
- **Update expenses**: Modify existing entries by ID
- **List expenses**: Filter by category or date
- **CSV storage**: Persistent data storage

```bash
pip install pandas
```

## Usage
```bash
python expense_tracker.py
```

## Commands
| Command | Description | Example |
|---------|-------------|---------|
| `add` | Add new expense | `add 2024-01-15 Groceries 45.67 "Weekly shopping"` |
| `update` | Update expense by ID | `update 2 50.00` |
| `list` | List all expenses | `list` |
| `list --category` | Filter by category | `list --category Groceries` |
| `list --date` | Filter by date | `list --date 2024-01-15` |

## Demo Run
```python
# expense_tracker.py
import pandas as pd
import os
from datetime import datetime

CSV_FILE = "expenses.csv"

def initialize_csv():
    if not os.path.exists(CSV_FILE):
        pd.DataFrame(columns=["id", "date", "category", "amount", "description"]).to_csv(CSV_FILE, index=False)

def add_expense(date, category, amount, description):
    df = pd.read_csv(CSV_FILE)
    new_id = 1 if df.empty else df["id"].max() + 1
    new_row = {"id": new_id, "date": date, "category": category, "amount": amount, "description": description}
    df = pd.concat([df, pd.DataFrame([new_row])], ignore_index=True)
    df.to_csv(CSV_FILE, index=False)

def update_expense(expense_id, new_amount):
    df = pd.read_csv(CSV_FILE)
    if expense_id in df["id"].values:
        df.loc[df["id"] == expense_id, "amount"] = new_amount
        df.to_csv(CSV_FILE, index=False)
    else:
        print(f"Expense ID {expense_id} not found.")

def list_expenses(category=None, date=None):
    df = pd.read_csv(CSV_FILE)
    if category:
        df = df[df["category"] == category]
    if date:
        df = df[df["date"] == date]
    print(df.to_string(index=False))

def main():
    initialize_csv()
    while True:
        cmd = input("> ").strip().split()
        if not cmd:
            continue
        if cmd[0] == "add" and len(cmd) == 5:
            add_expense(cmd[1], cmd[2], float(cmd[3]), " ".join(cmd[4:]))
        elif cmd[0] == "update" and len(cmd) == 3:
            update_expense(int(cmd[1]), float(cmd[2]))
        elif cmd[0] == "list":
            category = next((cmd[i+1] for i in range(len(cmd)-1) if cmd[i] == "--category"), None)
            date = next((cmd[i+1] for i in range(len(cmd)-1) if cmd[i] == "--date"), None)
            list_expenses(category, date)
        elif cmd[0] == "exit":
            break
        else:
            print("Invalid command. Usage: add <date> <category> <amount> <description> | update <id> <new_amount> | list [--category <cat>] [--date <YYYY-MM-DD>] | exit")

if __name__ == "__main__":
    main()
```
