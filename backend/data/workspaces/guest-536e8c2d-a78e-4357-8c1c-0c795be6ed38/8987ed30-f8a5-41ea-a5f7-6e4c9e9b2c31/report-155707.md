# Expense Tracker in Python

## Overview
A lightweight CLI expense tracker with CSV storage, supporting add/list operations. Built for simplicity and extensibility.

## Key Features
- **Add expenses**: Record date, description, amount, and category
- **List expenses**: View all entries with totals
- **CSV storage**: Persistent data in `expenses.csv`
- **Demo mode**: Sample run included

## Implementation

### Core Functions
```python
import csv
from datetime import datetime
from pathlib import Path

CSV_FILE = Path("expenses.csv")

def init_csv():
    if not CSV_FILE.exists():
        with open(CSV_FILE, 'w', newline='') as f:
            writer = csv.DictWriter(f, fieldnames=['id', 'date', 'description', 'amount', 'category'])
            writer.writeheader()

def add_expense(date, description, amount, category):
    init_csv()
    with open(CSV_FILE, 'a', newline='') as f:
        writer = csv.DictWriter(f, fieldnames=['id', 'date', 'description', 'amount', 'category'])
        writer.writerow({
            'id': datetime.now().strftime("%Y%m%d%H%M%S"),
            'date': date,
            'description': description,
            'amount': amount,
            'category': category
        })

def list_expenses():
    init_csv()
    with open(CSV_FILE, 'r') as f:
        reader = csv.DictReader(f)
        return list(reader)
```

### Demo Run
```python
if __name__ == "__main__":
    print("=== Expense Tracker Demo ===")

    # Add sample expenses
    add_expense("2023-11-01", "Groceries", "50.25", "Food")
    add_expense("2023-11-02", "Gas", "35.00", "Transport")
    add_expense("2023-11-03", "Coffee", "4.50", "Food")

    # List all expenses
    expenses = list_expenses()
    print("\nAll Expenses:")
    for exp in expenses:
        print(f"{exp['date']} | {exp['description']} | ${exp['amount']} | {exp['category']}")

    # Calculate total
    total = sum(float(exp['amount']) for exp in expenses)
    print(f"\nTotal: ${total:.2f}")
```
